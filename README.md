# Causal EMA–h-Hartley Learning-Rate Modulator

This repository implements and benchmarks the corrected **causal EMA–\(h\)-Hartley loss-feedback learning-rate controller** used as the machine-learning application of the accompanying convolution paper.

## Corrected proposed method

After optimizer update \(t\), the observed training loss is processed as

\[
\bar L_t=\alpha \bar L_{t-1}+(1-\alpha)L_t,
\qquad
u_t=\phi(\bar L_t),
\qquad
\phi(z)=\frac{z}{c+z}.
\]

The causal feedback is

\[
s_t=\frac h2\sum_{m=1}^{M}w(mh)\bigl(u_{t-m}-u_t\bigr),
\]

with normalized exponential weights

\[
w(mh)=\frac{2\rho^{m-1}}{h\sum_{j=1}^{M}\rho^{j-1}}.
\]

The executed next-step learning rate is

\[
\delta_t=\operatorname{clip}(\beta s_t,-\gamma,\gamma),
\qquad
\eta_{t+1}=r_{t+1}(1+\delta_t).
\]

Only \(u_t,u_{t-1},\ldots,u_{t-M}\) are used. There is **no future loss access and no artificial convolution delay**.

## Exact h-Hartley interpretation

Let the one-sided difference kernel be

\[
q_M(0)=-\frac12\sum_{m=1}^{M}w(mh),
\qquad
q_M(mh)=\frac12w(mh),\quad 1\le m\le M.
\]

Writing \(q_M=q_M^e+q_M^o\) into even and odd parts and \((Ru)(nh)=u(-nh)\), the implemented direct formula equals

\[
s_t=(q_M^e *_H u)(th)+(q_M^o *_H Ru)(th).
\]

The runtime uses the direct \(O(M)\) formula because the reflected terms cancel algebraically. The repository includes a numerical unit test verifying equality with the full even/odd \(h\)-Hartley decomposition.

## Main method names

| Method | Description |
|---|---|
| `ours_cosine` | Corrected EMA–\(h\)-Hartley feedback on cosine schedule |
| `ours_onecycle` | Corrected feedback on one-cycle schedule |
| `ours_warmup_cosine` | Corrected feedback on warmup-cosine |
| `ours_plateau` | No-gate corrected feedback on ReduceLROnPlateau |
| `ours_no_hc_*` | Replace the Hartley finite-memory operator by a one-step difference |
| `ours_no_ema_cosine` | Bypass EMA but keep the causal Hartley operator |
| `ours_no_phi_cosine` | Bypass the bounded control map |
| `ours_no_noise_norm_*` | Disable local variation normalization |
| `ours_no_gate_*` | Disable the trend-confidence gate |
| `ours_no_clip_*` | Disable theoretical clipping but keep emergency LR safety |
| `hc_gac_*` | Corrected EMA–Hartley feedback plus gradient-alignment confirmation |
| `ema_gac_*` | Separate dual-EMA gradient-alignment baseline |

Standard, random, L4, hypergradient, D-Adaptation, Prodigy, and AdamW baselines are retained.

## Mathematical tests added

`tests/test_hc_convolution.py` checks:

1. the exact causal index range \([t-M,t]\);
2. normalized kernel mass;
3. zero response for constant signals;
4. correct sign for increasing/decreasing signals;
5. incomplete-history protection;
6. exact equality between the direct formula and the even/odd \(h\)-Hartley decomposition;
7. EMA-before-\(\phi\) processing;
8. the no-EMA ablation;
9. clipping safety;
10. the convolution norm bound.

## Recommended paper-facing configuration

```text
alpha = 0.95
m_win = 3
rho = 0.8
gamma = 0.05
beta_fixed = 0.01
use_auto_beta = False
variance_normalize = False   # simplest exact theoretical method
trend_conf_tau = 0.0         # no-gate application section
use_clipping = True
```

For bounded \(0\le u_t\le1\) and normalized kernel mass, the conservative paper rule

\[
2\beta\lVert w\rVert_{1,M}\lVert u\rVert_\infty\le\gamma
\]

is guaranteed by \(\beta\le\gamma/2\). The defaults \(\beta=0.01\), \(\gamma=0.05\) satisfy this rule.

## Important result-compatibility note

Results generated by earlier delayed Hartley–cosine code are **not results of this corrected method**. The proposed-method and affected ablation experiments must be rerun. Dataset, model, optimizer, base-schedule, logging, and result-export code are unchanged.
